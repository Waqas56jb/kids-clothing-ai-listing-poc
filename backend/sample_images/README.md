# Sample images

These 12 images are a small subset of
[alexeygrigorev/clothing-dataset-small](https://github.com/alexeygrigorev/clothing-dataset-small)
(MIT license, see `LICENSE_clothing-dataset-small.txt`), used only to prove
the pipeline runs end-to-end and produces well-formed output.

This is **not** a real accuracy benchmark: these are adult clothing photos,
one item per photo, with no repeated photos of the same physical item — so
it cannot validate cross-photo same-garment matching accuracy (see
Section 52 of the project brief). Real accuracy validation needs actual
client photos of kids' clothing, including multiple photos of the same
physical item. Swap this folder's contents for real client images to get a
meaningful test once those are available.
